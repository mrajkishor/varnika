A VPN has two halves. Varnika is one of them.

Your phone runs Varnika. The other end is a server that you, your company, or a VPN provider runs. They only connect if each side knows the other's public key. Untick the box to see what happens when the server hasn't been told about your phone.

📱 Phone (Varnika)

  • private Its own private key. Never leaves the phone.
  • public The server's public key, to be sure it's the real server.
  • where The server's address: 203.0.113.10:51820

🛡️ Server

  • private Its own private key.
  • public The phone's public key, so it accepts the phone.
  • where The phone's tunnel address: 10.8.0.2

Kill switch: what happens when the tunnel drops

Mobile networks hiccup. Without a kill switch, apps quietly fall back to the open network. Android's built-in kill switch, which Varnika walks you through enabling, blocks everything until the tunnel is back.
